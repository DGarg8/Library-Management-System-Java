# 📚 Library Management System (Java)

## 📌 About the Project

The **Library Management System** is a console-based Java application developed as part of the Semester 3 Object-Oriented Programming (OOP) coursework.

The application provides basic library management functionality, allowing users to add books, search for books, display all registered books, issue books, return books, and remove books.

This project demonstrates the practical implementation of Java programming concepts, classes, objects, ArrayList, and basic data management operations.

## ✨ Features

- **Add Book:** Add a new book by entering its ID, title, and author name.
- **Search Book:** Search for a book using its unique ID.
- **Display All Books:** View the details and availability status of all registered books.
- **Issue Book:** Issue an available book by entering its ID.
- **Return Book:** Return a previously issued book.
- **Remove Book:** Remove a book from the library using its ID.
- **Duplicate ID Prevention:** Prevents adding books with an existing ID.
- **Input Handling:** Handles invalid menu choices and input errors.

## 🛠️ Technologies & Concepts Used

- **Programming Language:** Java
- **Collections Framework:** ArrayList
- **Classes and Objects:** Book and LibraryManagement
- **Exception Handling:** Try-Catch
- **Data Management:** Storing and managing book records using ArrayList
- **Conditional Statements:** Switch-case and if-else
- **Loops:** For-each loop and while loop
